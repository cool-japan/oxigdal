About

GeoSentinel searches the public Earth Search STAC catalog and reads Sentinel-2 Cloud-Optimized GeoTIFFs directly — NDVI, thresholding, polygonization and geodesic areas all run in WebAssembly, in this tab. No server ever learns which place you analyzed.
