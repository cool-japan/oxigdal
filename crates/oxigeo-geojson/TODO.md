- [x] TopoJSON encoder for shared-arc output (completed 2026-05-17)
  - **Done:** Three-phase TopoJSON 3.0 encoder at `src/topojson/`. Phase 1 — `quantize.rs`: `QuantBbox`, `QuantTransform { scale_x, scale_y, translate_x, translate_y }`, `compute_fc_bbox()`, `collect_all_rings()` with `RingSource` metadata; epsilon guard for degenerate zero-extent bboxes; default grid q=10_000.
